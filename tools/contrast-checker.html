색상 대비 검사기 사용 방법과 WCAG 기준

1. 색상과 명도 조절

배경색과 텍스트 색상을 입력하거나 색상 선택기와 명도 슬라이더로 조절하세요. 실시간 미리보기에서 텍스트와 그래픽에 같은 색상 조합이 적용됩니다.

2. WCAG 2.2 명암비 확인

일반 텍스트는 WCAG AA 4.5:1, AAA 7:1이 필요합니다. 대형 텍스트는 AA 3:1, AAA 4.5:1이며, 비텍스트 UI와 그래픽은 최소 3:1을 확인하세요.

3. 미달한 색상 조합 개선

결과가 기준에 미달하면 색상이나 명도를 조절한 뒤 다시 확인하세요. 색상값 변환이 필요하다면 HEX·RGB·HSL 색상 변환기를 이용해 보세요.
